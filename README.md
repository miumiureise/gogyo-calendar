# 陰陽五行カレンダー (GitHub Pages版)

伝統的な十干十二支と陰陽五行に基づいた、静的Webアプリのカレンダーおよび分析ツールです。

## 🌟 主な機能
- **月間カレンダー**: 日々の六十干支を自動計算し、五行の色で表示します。
- **五行相関図**: 相生（助ける）と相剋（抑える）のサイクルをインタラクティブなSVG図解で確認できます。
- **生年月日分析**: 出生日時から四柱（年・月・日・時）を算出し、五行のバランスをグラフで可視化します。
- **解説ページ**: 陰陽五行の基礎知識を体系的に学べます。

## 🚀 技術構成
- **Frontend**: React 18, TypeScript, Vite
- **Routing**: React Router (HashRouter) - GitHub Pagesのサブパス対応
- **Deployment**: GitHub Actions (自動ビルド・デプロイ)
- **Styling**: Inline Styles (CSS-in-JS) - 外部依存なしで高速動作

## 🌐 GitHub Pagesへの公開方法
本プロジェクトはGitHub Actionsによる自動デプロイが設定されています。
1. GitHubにリポジトリを作成し、コードをpushします。
2. `main` ブランチにpushされると、自動的に `project/dist` がデプロイされます。
3. リポジトリ設定の **Settings > Pages** で、Sourceを `GitHub Actions` に設定してください。

## ⚖️ 暦計算の方式と制限
- **計算方式**: 2000年1月1日を基準点とした経過日数ベースの計算を用いています。
- **制限事項**: 
    - 月柱および年柱の切り替えは、近似的な日付（2月4日頃）で行っています。
    - 厳密な天文暦（節気）に基づく秒単位の判定は行っておらず、簡易的な推計を用いています。
    - 本アプリは教育・娯楽目的であり、専門的な鑑定には適しません。
